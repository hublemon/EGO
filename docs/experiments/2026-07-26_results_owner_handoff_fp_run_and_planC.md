## 3. 무너진 두 지표 — 원인은 프롬프트 두 규칙

### 3-1. 페르소나 변경이 평가 프롬프트가 아니라 **감독 신호**를 바꿨다

1인칭 전환은 `vlm.py` 페르소나만 바꾼 것으로 보였지만, retrospective self가 쓰는 projected trace —
즉 **SFT 학습 타깃 자체** — 를 바꿨다. base·θ_CE에서는 영향이 없었고 SFT arm에서만 깨졌다.

**학습 타깃 실측** (`data/chosen_train.jsonl`, gate=pass)

| | 파일럿(3인칭) n=2,945 | fp(1인칭) n=2,494 |
|---|---|---|
| belief 최빈 5어절 점유율 | 31.9% `"the person is preparing to"` | **87.5%** `"i am in the middle"` |
| belief 어휘 종류 | 1,071 | 927 |
| **근거화율** | **24.4%** | **12.8%** |
| 제거화법 | 30.4% | **41.7%** |
| reasoning 평균 길이 | 81단어 | 82단어 (불변) |

평가 출력에서 증폭된다 — fp sft_r15의 belief 중 **94%**가 `"I am in the middle"`로 시작하고(파일럿 38%),
belief 어휘 종류는 566으로 무너진다(파일럿 1,039).

### 3-2. 원인 A — 규칙 4의 **예문**이 그대로 템플릿이 됐다 → belief 인과 붕괴

구 규칙 4: *"Never write intention forms like **'I am preparing to <next action>'** …;
describe the ongoing subgoal instead (e.g. **'I am in the middle of assembling the salad'**)"*

- 금지문이 **1인칭으로 쓰여** 3인칭에서는 어휘가 달라 작동하지 않았다(파일럿 의도형 잔존 37.7%).
  1인칭에서는 생성기가 쓰려던 것과 정확히 일치해 회피했다(fp 의도형 7.2%).
- 그러면서 규칙이 준 **긍정 예문 하나**가 타깃의 **87.5%**를 만들었다.

결과: belief가 서로 구별되지 않는 문자열이 되어 **swap 개입 자체가 약해졌다**(측정 감쇠).

### 3-3. 원인 B — 규칙 5가 reasoning에 판단을 몰아줬다 → G-NH 하락

구 규칙 5: *"<reasoning> should compare candidates against the evidence and **conclude toward the
actual next action**"* — reasoning을 **후보 소거 절차**로 만들었다. 근거 인용은 요구하지 않았다.

**인과 채널이 belief → reasoning으로 이동했다** (harden_s3, n=400)

| | belief | reasoning | **합** | belief 비중 |
|---|---|---|---|---|
| 파일럿 sft_r15 | **0.291** | 0.256 | 0.55 | 53.2% |
| fp sft_r15 | 0.098 | **0.483** | **0.58** | **16.8%** |

총 인과는 오히려 fp가 크다. **채널이 죽은 게 아니라 옮겨간 것**이고, 사전 등록 지표는 belief 쪽 절반만
쟀다. 개체 내 검정이 기전을 확인한다 — fp에서는 제거화법이 있으면 belief-swap flip이 0.058, 없으면
0.148(Δ−0.090)이고 reasoning 길이 4분위로도 단조 감소(0.160→0.080)한다. **파일럿은 평평하다**
(0.321 vs 0.329, Δ−0.008).

### 3-3b. belief-swap 전체 실측 — 논의에 쓰인 모든 값

**(i) harden_s3 — arm별 독립 실행, n=400 (fp) / n=800·405·388 (파일럿)** [측정]

`sensitivity = flip(swap_b) − flip(paraphrase)`. paraphrase는 문체 통제군이다.

| 코호트 / arm | belief | reasoning | both | flip_para | belief 비중 | n |
|---|---|---|---|---|---|---|
| fp / base | 0.0725 | 0.2200 | 0.8675 | 0.0075 | 24.8% | 400 |
| fp / cand_free | 0.0850 | 0.1850 | 0.8175 | 0.0075 | 31.5% | 400 |
| fp / θ_CE | 0.0925 | 0.1575 | 0.7925 | 0.0025 | 37.0% | 400 |
| **fp / sft_r15** | **0.0975** | **0.4825** | 0.8225 | 0.0125 | **16.8%** | 400 |
| 파일럿 / sft_r0 (ρ=0) | 0.2840 | 0.3457 | 0.7630 | 0.0469 | 45.1% | 405 |
| **파일럿 / sft_r15** | **0.2913** | 0.2562 | 0.7650 | 0.0350 | **53.2%** | 800 |
| 파일럿 / wise_a050 | 0.1160 | 0.2423 | 0.7655 | 0.0180 | 32.4% | 388 |

**총 인과(belief + reasoning)는 보존된다** — fp sft_r15 **0.58** vs 파일럿 sft_r15 **0.55**.
fp의 reasoning 민감도 **0.483**은 두 코호트 전 arm 중 최고값이다. 즉 SFT가 인과 채널을 심는 데
실패한 것이 아니라 **belief 대신 reasoning에 심었고**, 사전 등록 지표가 belief 쪽 절반만 쟀다.

**(ii) 개체 내 검정 — 왜 옮겨갔나** [측정]

같은 arm 안에서 reasoning 문체별로 belief-swap flip을 나눈 값. 제거화법 = `other/remaining/alternative
candidates` 패턴.

| | 제거화법 있을 때 | 없을 때 | Δ |
|---|---|---|---|
| **fp sft_r15** | 0.058 (n=171) | **0.148** (n=229) | **−0.090** |
| 파일럿 sft_r15 | 0.321 (n=237) | 0.329 (n=563) | −0.008 |

reasoning 길이 4분위로 보면 fp는 **단조 감소**(0.160 → 0.100 → 0.100 → 0.080), 파일럿은 **평평**
(0.310 / 0.325 / 0.350 / 0.320). → fp에서는 **reasoning이 후보 소거를 끝내면 belief가 할 일이 없다.**

**(iii) 측정 감쇠 — belief 자체가 서로 구별되지 않는다** [측정]

| | 파일럿 sft_r15 | fp sft_r15 |
|---|---|---|
| belief 최빈 5어절 점유율 (평가) | 38.2% | **94.1%** |
| belief 어휘 종류 (평가) | 1,039 | **566** |
| belief 쌍별 Jaccard | 0.230 | **0.324** |

donor belief와 본인 belief가 **같은 5어절로 시작하는 사실상 중복 문자열**이므로, 스왑 개입 자체가
약해진다. 이는 모델의 감수성이 낮은 것과 **구별되지 않는 교란**이다.

**(iv) harden_paired — 교란 3개를 고친 프로토콜, 파일럿 코호트에만 존재** [측정]

`tools/harden_paired.py`가 `harden_s3`의 교란을 각각 고정한다:
① 모집단 불일치(arm마다 다른 표본) → 공통 sample_id 셋 1개를 전 arm이 같은 순서로 사용
② swap partner가 arm 내부에서 나옴(문체 정보량이 arm마다 다름) → `swap_b_shared`로 **전 arm 동일
문자열** 주입 ③ paraphrase를 평가 대상 모델 자신이 생성 → base 모델 1개로만 생성해 공유.
추가로 **프레임 포함 vision-grounded 채점**과 assistant 헤더 중복을 고쳤다.

파일럿 코호트, n=230:

| arm | belief (own donor) | belief (**shared donor**) | reasoning | U_b |
|---|---|---|---|---|
| base | 0.0478 | 0.0478 | 0.2261 | 0.0167 |
| θ_CE | 0.0609 | 0.0696 | 0.1391 | 0.0227 |
| **sft_r15** | **0.2174** [.157, .278] | **0.2435** [.183, .304] | 0.3565 | 0.0448 [.029, .062] |

**G_CC2** (학습 arm − base, 동일 셋 짝지음):

| | point | 95% CI | 판정 |
|---|---|---|---|
| sft_r15 − base (own) | **+0.1696** | [0.1043, 0.2304] | **PASS** |
| sft_r15 − base (shared) | **+0.1957** | [0.1304, 0.2609] | **PASS** |

→ *"Retrospection이 base·Prospection-only에는 없는 belief 인과 채널을 만든다"*는 주장은
**파일럿 코호트에서 유의하게 성립한다.**

**(v) [정정] 프로토콜 눈금 — 절대 임계를 교차 적용하지 말 것**

같은 코호트·같은 arm(파일럿 sft_r15)인데 프로토콜에 따라 **0.2913(harden_s3) vs 0.2174(harden_paired)**
로 약 25% 낮게 읽힌다. 사전 등록 임계 0.20은 harden_s3 눈금으로 정한 값이므로, harden_paired의
0.2174를 0.20에 대는 것은 **다른 자로 재고 같은 눈금을 읽는 것**이다.
→ **절대 임계 대신 G_CC2를 주 판정으로 쓴다.** 프로토콜 내부 비교라 눈금 문제가 없다.

**(vi) 비어 있는 칸**

|  | harden_s3 | harden_paired |
|---|---|---|
| 파일럿 코호트 | 있음 (0.2913) | **있음 (0.2174 / G_CC2 PASS)** |

### 7-5. 추정이 빗나갈 수 있는 지점 (미리 적어둘 것)

   그대로다 → 축 4의 인과 해석을 약화해야 한다(gx의 "가설 기각" 분기와 동일 논리).
2. **규칙 4가 belief를 다양화하되 변별력을 못 줄 수 있다.** 어휘는 늘고 belief 인과는 그대로일 수 있다.
3. **GATE_GO 통과율이 떨어질 수 있다.** 규칙이 요구를 늘렸으므로 gate 탈락이 늘면 학습 표본이 준다.
   Φ 재생성 직후 pass율을 먼저 확인하고, 크게 떨어지면 규칙 문구를 완화한다.
