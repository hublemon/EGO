## 2. 1인칭율을 기각하는 구체적 근거 6가지

Results에서 "egocentric reasoning이 1인칭 화법으로 드러난다" 류의 서술을 **쓰지 않는 이유**.
(부록·각주에서 조건을 달아 언급하는 것은 가능 — §7 참조.)

| # | 근거 | 실측 |
|---|---|---|
| R1 | **템플릿의 함수** — 무학습 base가 프롬프트 프레임만으로 값이 요동 | base 1인칭율 74.0%(파일럿 v2/v3) / 51.6%(제시 레짐) / **0.0%**(cesft_v2 3인칭) / 93.5%(fp battery) |
| R2 | **레짐의 함수** — 같은 모델·같은 체크포인트가 입력 형식에 따라 갈림 | cand_free: battery **30.7%** vs freegen **91.0%** |
| R3 | **입력 길이의 함수(용량-반응)** — 학습 효과가 아니라 프롬프트에 쌓인 무주어 history 줄 수에 비례 | H0 92.6%(무침식) → H1–3 73.3% → H4–7 37.7% → H8+ **21.0%** |
| R4 | **천장 효과** — fp에서는 base가 이미 93.5/99.2%라 "강화"가 원리적으로 측정 불가 | 파일럿의 +8.9pp 강화는 base 51.6%였기에 가능했던 값 |
| R5 | **정오와 무연결(이번 신규 검정)** — 화법이 정확도를 예측하지 못하며 오히려 역방향 | cand_free 내부: 주석문체 서두 SelAcc **29.7%**(n=451) > 1인칭 서두 **16.1%**(n=298) |
| R6 | **선행 판정 존재** | crosscohort §2-6 "1인칭율은 표면형 지표, 본문 능력지표 사용 금지" |

**R5가 결정적이다.** 축 채택 기준("정오와 연결되지 않으면 능력으로 인정하지 않는다")을 1인칭율에
적용하면 통과하지 못한다. 같은 기준으로 축 4는 통과했고(+19.6pp), 대조 접속 표현은 탈락했다(+0.9pp).

**그럼에도 1인칭 일원화(07-25)를 한 이유**는 능력 때문이 아니라 **측정 가능성** 때문이다 — 3인칭
템플릿에서는 전 arm이 0%에 붙어 arm 간 차이 관찰 자체가 불가능했다(R1). 이 사실은 Methods나
부록의 실험 설정에 한 문장으로 적는 것이 정확하다.

## 3. 채택된 능력 축 5종 — 정의와 계산

> **축 채택 기준 (불변)**: trace 수준 성질은 **동일 arm 내부에서 정오를 분리할 때에만** 능력으로
> 인정한다. 빈도만 움직이고 정확도와 무관하면 통제 지표로만 보고한다. 이 기준으로 축 4는 통과,
> 1인칭율(R5: 역방향)과 대조 접속 표현(+0.9pp)은 탈락했다. 2026-07-26 Experiments 섹션에
> `\paragraph{Metric adoption criterion.}` 으로 사전 선언을 명문화했다 — 그전에는 Results의
> `Excluded proxy` 문단이 사후 기각처럼 읽혔다.

모두 `runs/<run>/eval/{arm}.records.jsonl` × `data/context_val.jsonl` 조인, **공통 covered 교집합**
(gt_rank≤10 ∧ 전 arm 존재 ∧ non-malformed), n=1000. 신규 추론 없음.

| 축 | 정의 | 왜 능력인가 |
|---|---|---|
| **1. G1 유지** | WM top-1이 정답인 부분집합에서의 SelAcc | 경계가 이미 준 정답을 지켜내는 힘. 대조군에서 침식됨 |
| **2. G2 교정** | WM top-1이 오답인 부분집합에서의 SelAcc | top-1을 넘어 재선택하는 힘 = C2의 직접 측정 |
| **3. 연속 판별 회수율** | GT가 직전 행동의 연속인 샘플(310/1000, 31.0%) 중 맞힌 비율 | 연속 선택은 정밀도 0.71–0.72의 고정밀 신호 → 관건은 회수율. history 없이는 불가능 |

| **5. belief 내용성** | task_belief가 선택 action 문자열과 동일한 비율(낮을수록 좋음) + harden 개입의 belief 인과 | 표층(echo)과 개입(인과)이 같은 방향으로 수렴 |

`(prior|previous|earlier) (action|actions|step|steps|pattern)` · `established pattern` · `repeatedly` ·
`pattern of (action|behavior)` · `consistent with the (prior|previous|established|ongoing)`

### 3-5. 축 4-b — 궤적 서술 vs 패턴 인용 (2026-07-26 추가)

축 4의 "언급"을 형태로 쪼갠다. 표면은 둘 다 history 언급인데 결정 가치가 정반대다.

**읽는 법 세 가지.**

1. **서술은 전 arm에서 음의 연관**이다(−9.8 ~ −16.6pp, 전부 CI가 0 배제). 관찰을 옮겨 적는 것은
   판단이 아니다. 축 4가 "history를 말하면 잘 맞는다"는 뜻이 아님을 이 행이 증명한다.
2. **"history를 말했다"를 고정해도**(서술O 부분집합) 인용 효과가 sft_r15 +15.8pp,
   gx +12.2pp, base +12.7pp로 살아남는다. **cand_free만 +1.5pp로 소멸한다.**
3. **cand_free는 인용 전용 trace를 353건**(전 arm 최다) 만들면서 이득이 0이다. 반면 sft_r15의
   인용 전용 셀 56.5%는 전체 프로파일에서 관측된 최고값이다. 정답만 학습하면 시간 근거의
   **어휘**는 배우지만 그것을 쓸모 있게 만드는 **추론**은 배우지 못한다.

**주의**: sft_r15의 인용 조건 셀은 62/60건으로 작다. 축 4와 마찬가지로 **관찰적 조건부 연관이며
인과가 아니다.** 인과 개입은 history strip과 belief swap 둘뿐이다.

### 3-6. 기각된 축 (Results에 쓰지 말 것)

**인과 접속 표현**("since"/"because"/"therefore"/"thus") — **가장 교훈적인 기각.**
빈도 패턴이 우리 서사와 정확히 일치한다: base 18.9% → cand_free **5.4%**(붕괴) → sft_r15
**20.5%**(전 arm 최고로 회복). "정답만 학습하면 정당화를 잃고 EGO는 되찾는다"로 읽으면 완벽한
능력 서사가 된다. **그런데 채택 기준을 통과하지 못한다.** arm 내부 정오 연관이 음수다:

| arm | 인과접속률 | 언급 시 | 미언급 시 | Δpp | 95% CI |
|---|---|---|---|---|---|
| base | 18.9% | 18.8 | 22.0 | −3.1 | [−10.8, +3.8] |
| cand_free | **5.4%** | 13.2 | 22.7 | −9.5 | [−20.0, +2.4] |
| θ_CE | 11.3% | 26.9 | 30.5 | −3.7 | [−14.0, +7.3] |
| **sft_r15** | **20.5%** | 21.1 | 28.8 | **−7.7** | **[−14.3, −0.5]** |
| sft_r15_gx | 15.0% | 30.8 | 29.4 | +1.4 | [−8.2, +10.1] |

**정당화의 문법을 생산하는 것과 판단을 생산하는 것은 다르다.** 빈도만 봤다면 결론이 뒤집혔을
사례이므로 Results에 반례로 **명시적으로 싣는다**(리뷰어의 "유리한 지표를 사후 선택한 것 아닌가"
질문에 대한 직접 답변). 산출: `capability_axes.json` 의 `rejected_causal_*`,
CI 는 `eval/rejected_causal_connective_ci.json` (video-cluster bootstrap B=4000 seed=42).

**대조 접속 표현**("rather than"/"but not"): sft_r15에서 0.4%→**10.4%**로 26배 증가(θ_CE 0.2%,
cand_free 0.2%)해 가장 눈에 띄지만, sft_r15 **내부** 유무별 SelAcc가 31.7% vs 30.8%(**Δ+0.9pp**)로
무의미 → Retrospection Φ 타깃 문체의 이식 흔적일 뿐. **능력으로 서술 금지.**
